Why "make it better" never works

Asking for better, premium, or more modern just moves you to a different point in the same crowded middle. These words have no edges — the model resolves them to the average of themselves.

moderncleanpremiumsleekprofessionalminimal

The move: narrow the range

Replace every adjective with something the model can obey — a hex code, a pixel value, a named reference, a hard prohibition. The average has nowhere to hide when only one answer fits.

the law

AI cannot be creative for you. It can only be accurate for you. Creativity happens in what you choose to look at and what you decide to steal — before you type anything. If you skip that, the model fills the gap with its default, and its default is the average.

08 → 03

Two rules that make it work

Declare the legend in the prompt. Models read annotated images well — but only if you say what green and blue mean. Otherwise they're just colors.

Be literal on the image, be about intent in the prompt. The image gives the model geometry. The prompt gives it a goal to resolve ambiguity against.

Figure 5 — steps 4 & 5, the reverse-engineering
Never ask for a site. Ask for a spec.
Asking for code makes the model interpret an image and generate a page at the same time — and it silently swaps half your reference for its defaults. Split it. The spec is a page of text where drift is visible in sixty seconds; in generated code the same drift is invisible until the result looks wrong and you can't say why.

why it holds

The spec is the deliverable, not the site. If the spec is right, the site is right — and if the model drifts three sections in, you don't re-prompt from scratch, you point back at the spec. Ask it to flag every place the reference structure conflicts with your brand rules and say which should win. That single instruction surfaces the decisions it would otherwise make silently.

TEST 1
Only one way to obey it?

Read one line. Ask whether it could be satisfied two different ways.

"Big headline" has a thousand valid answers. "72px, max 2 lines" has one. If a line has more than one right answer, the model picks — and it picks the most common.

TEST 2
The two-builders test

Paste your spec into two fresh sessions. Build it twice, from nothing.

✓
Same page → it's a spec. Wherever the two diverge is exactly where slop gets in — those gaps are your unmade decisions, and the test finds them for you.
SIZE
Length is the forcing function
1 page
60 seconds
The whole point is that you can audit it at a glance. At eight pages you won't read it, you won't catch the drift, and you've written the build by hand in a worse format. The size limit is what sets the detail level.
TRAP
The absences are spec too

Beginners only write what should exist. That leaves every shouldn't open — and the model's defaults are almost entirely shouldn'ts.

No gradients.No secondary CTA. No accent color.No shadows. No logo strip.Nothing pill-shaped.
