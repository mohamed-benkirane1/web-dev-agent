# Web Dev Agent — Système de Direction IA pour le Design

Une méthodologie pour diriger les outils IA (LLMs) afin qu'ils produisent des interfaces qui reflètent une identité de marque précise — plutôt que le rendu générique et moyen que ces modèles produisent par défaut.

## Le problème

Des prompts vagues ("moderne, épuré, premium") ne donnent au modèle aucune contrainte réelle à respecter, donc il retombe sur la moyenne statistique de tous les sites qu'il a vus. Le résultat est reconnaissable entre mille : dégradé violet-bleu, halo flou en fond, trois cartes avec icône, glassmorphism, deux boutons d'action à égalité — les mêmes tics, sur chaque site généré par IA sans contrainte.

## La méthode — 8 étapes

1. **Brand Core** — des contraintes, pas des adjectifs : chaque ressenti devient un code hex ou une valeur en pixels
2. **Hunt** — 7+ références réelles, 2 anti-références
3. **Mark** — annoter les références avec une légende fixe (garder / structure seulement / supprimer / remplacer / ordre de lecture)
4. **Extract** — le modèle rédige un cahier des charges à partir des images annotées, pas de code encore
5. **Translate** — le cahier des charges est réécrit avec les valeurs de la marque
6. **Build** — construction section par section, chaque section validée avant de passer à la suivante
7. **Filter** — passage dans une checklist de 12 signes de rendu générique avant de livrer
8. **Loop** — capture du résultat, annotation avec la même légende, nouvelle passe

## Pourquoi c'est important

C'est le processus derrière le travail de design web piloté par IA dans ce portfolio — ce qui empêche un rendu automatisé de ressembler à du contenu IA générique, et transforme un brief vague en quelque chose qu'on peut vraiment imposer à un modèle.
